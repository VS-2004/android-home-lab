# Lessons Learned

This document captures key insights gained while planning and setting up the Android Home Lab project.

## Planning Before Implementation
Documenting architecture and decisions before installation helped avoid unnecessary rework and confusion.

## Simplicity Matters
Choosing simpler tools (like Termux) reduced setup friction and made learning more effective.

## Documentation Is a Skill
Writing clear documentation required deliberate effort but significantly improved project clarity.

## Constraints Drive Better Design
Limited hardware resources encouraged efficient design choices and realistic expectations.

## GitHub as a Learning Tool
Using issues, commits, and documentation turned GitHub into more than just a code host—it became part of the learning process.
