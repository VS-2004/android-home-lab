# Android Home Lab Server

## Overview
This project documents the process of turning an old Android tablet into a private, headless home-lab server controlled from macOS. The goal is to learn Linux fundamentals, networking, and basic service management using minimal hardware.

## Status
🚧 Project is in early setup and documentation phase.

## Goals
- Learn Linux basics through hands-on experimentation
- Understand networking using real services
- Practice remote system administration
- Build a documented GitHub learning project

## Why This Project?
Old Android tablets are often unused but still powerful enough for lightweight services. This project explores how such hardware can be repurposed into an educational home-lab environment.

## Current Setup
- Control machine: macOS
- Server device: Android tablet
- Network: Local network only
